您只需要準備：

  • 一個正常的 Google 帳號（Gmail 帳號）。
  • 一部電腦（建議使用 Google Chrome 瀏覽器操作設定，約 3～5 分鐘）。
  • 永久免費：不需綁定信用卡、不需租用任何主機或伺服器。
步驟 1

一鍵「建立副本」獲取個人專屬試算表與程式碼

  1. 點擊作者分享的專屬AI小助理範本連結（點我前往範本）。
  2. 網頁開啟後，畫面中央會跳出對話框：「您要建立「AI小助理(範本)」的複本嗎？」。
  3. 請直接點擊按鈕：「建立副本」。
🎉 自動打包完成！ Google 會將包含 5 大專屬分頁（聯絡人、記帳本、行事曆、生活雜事、好物分享）、精緻彩色表頭以及後端全套 AI 程式碼，100% 複製到您的雲端硬碟中！您完全不用手動建立任何欄位。

▲ 點擊「建立副本」後產生的個人 Google 試算表畫面（已內建 5 大分頁與彩色表頭樣式）

步驟 2

免費領取 Google Gemini API 金鑰（API Key）

AI 的辨識大腦來自 Google 官方的 Gemini 模型，每個人都可以免費領取專屬金鑰：

  1. 打開瀏覽器，前往 🔗 前往 Google AI Studio 官網。
  2. 登入您的 Google 帳號，並勾選同意條款。
  3. 點擊畫面右上角的按鈕：「Create API key」（建立 API 金鑰）。

    ▲ 點擊「Create API key」按鈕

  4. 在彈出的視窗中點擊右下角的 「Create key」（建立金鑰）按鈕。

    ▲ 彈出「Create a new key」視窗後，點擊右下角紅框處的「Create key」

  5. 金鑰產生後，點擊彈窗右下角的 「Copy key」（複製金鑰）按鈕。

    ▲ 點擊右下角紅框處的「Copy key」按鈕複製金鑰

💡 小提醒：金鑰可能是以 A... 開頭的一長串文字。Google 提供個人帳號非常充足的每日免費額度，生活記帳與日程管理完全足夠，不會被扣款！
步驟 3

一鍵快速填入 Gemini API Key（免複製試算表網址）

✨ 全自動升級：本系統已全面自動化偵測試算表綁定，您完全不需要手動複製試算表網址，只需貼上 API Key 一次即可！

🌟 推薦方式：直接在試算表功能表一鍵填入（最簡單）

  1. 回到您在【步驟 1】建立好的 Google 試算表分頁。
  2. 點擊頂部功能表：👉 【🤖 AI 智慧小助理】 ➜ 【⚙️ 快速填入 Gemini API Key】。
    💡 小提醒：剛建立好副本若尚未看到此選單，請重新整理網頁（F5 或重新載入）一次即可出現！

    ▲ 點擊頂端功能表「🤖 AI 智慧小助理」➜「⚙️ 快速填入 Gemini API Key」

  3. 首次執行授權：若是第一次點擊，Google 會彈出安全授權流程：
    • 3.1 彈出「需要授權」對話框，點擊 「確定」 ➜ 選擇您的 Google 帳號。

      ▲ 首次執行會彈出「需要授權」視窗，點擊藍色「確定」按鈕

    • 3.2 出現「「AI 智慧雲端小助理」要求存取您的 Google 帳戶」畫面，點擊勾選 「全選」。

      ▲ 勾選「全選」以授予必要之雲端小助理存取權限

    • 3.3 捲動到畫面最底部，點擊 「繼續」 按鈕完成授權。

      ▲ 捲動至最底部，點擊「繼續」

  4. 貼上金鑰並儲存：授權完成後，畫面上會彈出「設定 Gemini API Key」對話框（若授權後未自動跳出，再次點選選單「快速填入 Gemini API Key」即可）：

    在輸入框中直接貼上在【步驟 2】取得的 AIzaSy... 金鑰，點擊 「確定」。

    ▲ 貼上您的 Gemini API Key，點擊「確定」

  5. 🎉 完成綁定！ 畫面跳出「設定成功」提示，系統已自動將 API Key 與目前試算表全自動綁定，完全免去敲打後台代碼！

    ▲ 畫面跳出「🎉 設定成功！」提示，代表 API Key 與試算表已自動完成綁定

🛠️ 備用方式：在 Apps Script 專案設定手動新增（點此展開）

若您偏好在後台管理，也可以透過此傳統方式填入（系統已自動偵測試算表，因此僅需填寫 GEMINI_API_KEY，免填 SHEET_URL）：

  1. 點擊頂部功能表：「擴充功能」 ➜ 「Apps Script」。
  2. 點擊左側選單的 ⚙️ 「專案設定」 ➜ 捲動至底部點擊 「新增指令碼屬性」。
  3. 屬性名稱填 GEMINI_API_KEY，值貼上步驟 2 複製的金鑰，最後點擊 「儲存指令碼屬性」 即可。
步驟 4

執行權限授權與自我檢測（打通日曆與聯絡人）

為了讓 AI 具備自動寫入 Google 日曆與 Google 通訊錄的權限，需要進行一次性安全檢測與授權：

🌟 推薦方式：直接在試算表功能表一鍵檢測（最簡單）

  1. 回到 Google 試算表視窗，點擊頂部功能表：👉 【🤖 AI 智慧小助理】 ➜ 【🚀 執行權限授權與自我檢測】。

    ▲ 點擊功能表「🤖 AI 智慧小助理」➜「🚀 執行權限授權與自我檢測」

  2. 授權確認流程（若在步驟 3 已完成授權，此步驟會自動略過直接顯示檢測成功）：
    • 2.1 若彈出「需要授權」視窗，點擊藍色 「確定」 按鈕 ➜ 選擇您的 Google 帳號。

      ▲ 首次執行會彈出「需要授權」視窗，點擊藍色「確定」按鈕

      💡 若畫面跳出「Google 尚未驗證這個應用程式」警告，請點擊左下角 「進階」 ➜ 最下方 「前往「AI小助理」（不安全）」 即可繼續。
    • 2.2 出現「「AI 智慧雲端小助理」要求存取您的 Google 帳戶」畫面，點擊勾選 「全選」。

      ▲ 勾選「全選」核取方塊以授予必要存取權限

    • 2.3 捲動到畫面最底部，點擊 「繼續」。

      ▲ 捲動至最底部，點擊「繼續」

  3. 檢測成功！ 畫面會彈出「🎉 檢測成功！」提示框，代表日曆與聯絡人雙向授權已 100% 打通：

    ▲ 彈出「🎉 檢測成功！」代表系統已就緒，可直接進行下一步「正式發布」

🛠️ 備用方式：在 Apps Script 編輯器後台執行 testAllPermissions（點此展開）

若您偏好在後台查看詳細執行紀錄，亦可透過此方式檢測：

  1. 點擊「擴充功能」➜「Apps Script」，點擊左側工具列最上方的 <>「編輯器」。
  2. 頂端函式下拉選單選擇：👉 testAllPermissions，點擊旁邊的 「執行」（▶️ 播放圖示）。
  3. 下方「執行紀錄」輸出「雙向授權已 100% 打通」即代表成功：
步驟 5

發布上線（網頁應用程式部署）

現在我們要將系統正式發布為專屬網頁，產生讓手機和電腦隨時使用的專屬網址：

  1. 回到 Google 試算表，點擊頂端選單：👉 「擴充功能」 ➜ 「Apps Script」 開啟後台編輯器（若您已在 Apps Script 編輯器分頁，可直接在該分頁操作）。

    ▲ 點擊頂端選單「擴充功能」➜「Apps Script」開啟後台編輯器

  2. 在編輯器畫面右上角，點擊藍色按鈕：👉 「部署」 ➜ 「新增部署作業」。

    ▲ 點擊右上角藍色按鈕「部署」➜「新增部署作業」

  3. 點擊左上角的齒輪圖示 ⚙️ 「選取類型」 ➜ 選擇 「網頁應用程式」。

    ▲ 點擊齒輪圖示「選取類型」➜ 選擇「網頁應用程式」

  4. 依照下列紅框設定填寫，最後點擊右下角的藍色 「部署」 按鈕：
    • 新增說明：輸入 v1.0 正式上線
    • 執行身分：選擇 「我 (您的帳號)」（⚠️ 請勿選存取者，確保系統有權限操作您的雲端）。
    • 誰可以存取：選擇 「所有人」（方便手機開啟免反覆登入）。

    ▲ 設定說明、執行身分（我）、誰可以存取（所有人），點擊右下角「部署」

  5. 部署完成後，在「網頁應用程式」區塊點擊 「複製」 網址（網址結尾為 /exec）。

    ▲ 點擊網頁應用程式網址下方的「複製」，取得專屬小助理連結

🚀 大功告成！ 這串網址就是您專屬的「AI 智慧雲端小助理」網站！
步驟 6

加入手機主畫面（秒變專屬原生 App）

將網址傳至手機打開，免去每次都要輸入網址的麻煩：

🍎 iPhone 使用者 (Safari)

  1. 用 Safari 開啟該網址。
  2. 點擊螢幕下方中央的 「分享」按鈕（向上箭頭）。
  3. 滑動選單點選 「加入主畫面」。
  4. 輸入名稱「AI小助理」➜ 點擊「新增」。

🤖 Android 使用者 (Chrome)

  1. 用 Chrome 開啟該網址。
  2. 點擊右上角 「三個點」選單。
  3. 點選 「安裝應用程式」 或 「新增至主螢幕」。
  4. 點擊「新增」。

❓ 常見問題（FAQ）

Q1：拍了名片之後，手機通訊錄真的會出現嗎？
是的！只要您手機登入的是同一個 Google 帳號，名片上的姓名、電話、單位與職稱就會在 3 秒內自動同步到您手機的 Google 聯絡人中，完全不用手動輸入。
Q2：為什麼點擊網頁表格裡的「🗓️ 已同步Google日曆」會開啟日曆？
系統提供智慧直達功能，點擊該徽章會直接在新分頁開啟 Google 日曆，並自動跳轉定位到該行程的當天視圖，方便您立刻核對。
Q3：未來如果想要修改或升級程式，網址會變嗎？
不會！只要在 Apps Script 點「部署 > 管理部署作業 > 編輯 > 版本選擇新版本 > 部署」，網址永遠維持不變，手機桌面上的 App 也能自動獲取最新功能。
Q4：我的資料放在哪裡？安全嗎？
100% 安全！所有的資料只存放在您自己的 Google 雲端試算表與日曆中，沒有經過任何第三方廠商伺服器，永久擁有最高的隱私權與所有權。
